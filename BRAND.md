# Kelp & Co — brand guidelines (fictional demo brand)

Demo brand for a portfolio prototype of a "prompt -> on-brand files" system. Not a real company.

## Palette
| Name | Hex | Use |
|---|---|---|
| Deep sea | #0F4C5C | backgrounds, headlines on light |
| Sand | #F3E9D2 | page background, cards |
| Burnt orange | #E36414 | one accent per layout: buttons, highlights |
| Ink | #1B1B1B | body text on sand |
| Foam | #FFFFFF | text on deep sea, logo margin |

## Type
- Display: Georgia, bold, tight tracking. Headlines only.
- Body: Segoe UI, regular. Never below 16 px on web, 28 px on social posts.

## Layout rules
1. One accent color per layout, always burnt orange, never two accents.
2. Text on deep sea is Foam. Text on Sand is Ink or Deep sea.
3. Logo has clear space equal to the width of the kelp leaf on every side; minimum 64 px wide.
4. Social posts: 1080x1080, 80 px safe margin, headline max 6 words.
5. No gradients, no photo effects, flat shapes only.

## Voice
Plain, warm, short sentences. Name the coffee and the place. No superlatives.

## Checks the system runs on every output
- every color used is in the palette (tolerance 6 per channel);
- text and background pair contrast at least 4.5:1;
- logo clear space respected;
- file dimensions match the asset type.
